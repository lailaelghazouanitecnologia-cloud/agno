## Instructions
Fix the failing tests and errors. You must:

1. Read the error messages carefully
2. Identify the root cause in the source code
3. Fix the implementation (not the tests, unless the test expectation is wrong)
4. Re-run the tests to verify the fix
5. Repeat until all tests pass

## Rules
- Fix ONE issue at a time — don't try to fix everything at once
- After each fix, re-run tests to check progress
- If a fix breaks other tests, revert and try a different approach
- Document what was wrong and how you fixed it
